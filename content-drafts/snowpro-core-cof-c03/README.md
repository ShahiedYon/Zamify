# SnowPro Core ten-question starter

Original authoring draft for the Zamify study-pack expansion. Independent subject review and app integration are pending. The JSON intentionally lives outside Android release assets.

| Domain | Question IDs | Focus |
| --- | --- | --- |
| Architecture | 1, 2, 3 | Warehouse concurrency, Cortex retrieval, table retention |
| Governance | 4, 5 | Role inheritance and column masking |
| Loading | 6, 7 | Rows versus files and load versus unload direction |
| Performance | 8, 9 | Partition pruning and persisted results |
| Collaboration | 10 | Reader-account billing |

Each item uses the existing Zamify question fields, with an additional examId namespace. Keys are zero-based option indices. This starter's distribution is an editorial approximation for ten items. Map every objective against the current official study guide before publication. All ten are single-answer items in this first draft. The complete pack should also include original multiple-response items where appropriate.

No item is copied from the user's screenshots, a YouTube question bank or recalled live exam content. These are new scenarios derived from public Snowflake documentation.
